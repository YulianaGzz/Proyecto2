## Algoritmia y Optimización Proyecto 2 - Ejercicios

## Descripción
 Implementación de algoritmos de optimización y análisis de su rendimiento mediante experimentos y gráficas en 5 Ejercicios.

## Ejercicios
- Aceleración paralela: estimación de Pi con diferentes procesos.
- Greedy Knapsack: comparación de estrategias voraces.
- TSP: búsqueda local con heurística 2-opt.
- Simulated Annealing: comparación de esquemas de enfriamiento.
- MST Approximation: análisis y comparación de soluciones para el TSP.
Tecnologías
Codigo con Python.
